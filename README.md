# Flipkart Price Scraper Chrome Extension

This extension allows you to upload an Excel file containing FSNs and download a file with their current prices.

# How to Install
1. Click the green **Code** button and select **Download ZIP**.
2. Extract the ZIP file on your computer.
3. Open Chrome and go to `chrome://extensions/`.
4. Turn on **Developer mode** (top right).
5. Click **Load unpacked** and select the extracted folder.

## Usage
1. Prepare an Excel file with a column header named **FSN**.
2. Click the extension icon, upload your file, and click **GET PRICES**.
